# 📖 Жас ерекшелік психологиясы — Электрондық оқулық

Заманауи, жеңіл және таза веб-платформа. Delphi десктоп қосымшасынан толық вебке көшірілген.

## ✨ Мүмкіндіктері
- **Толық мазмұн**: Кіріспе, 14 дәріс, 15 практикалық сабақ, 10 СӨЖ (студенттің өздік жұмысы).
- **Интерактивті бақылау тесті**: 
  - 15 ресми сұрақ (Paradox базасынан алынған, қазақ тілінің әріптері толық түзетілген).
  - Студенттің аты-жөнін тіркеу, нұсқаларды кездейсоқ араластыру.
  - Нәтижелерді бағалау (Өте жақсы / Жақсы / Қанағаттанарлық) және хаттаманы басып шығару (Print protocol).
- **Ыңғайлы оқу құралдары**:
  - Ақ қағаз (Light), Жылы сепия (Sepia) және Түнгі режим (Dark).
  - Қаріп өлшемін реттеу (A- / A+).
  - Оқу барысын бақылайтын прогресс жолағы (Reading progress bar).
  - Бөлімдер бойынша толықмәтінді жылдам іздеу (Ctrl+K).
  - Толық экран және басып шығару стильдері.
- **Жоғары жылдамдық**: Жасанды интеллект неондары мен артық фреймворктерсіз, таза академиялық стиль.

---

## 🚀 Жергілікті іске қосу (Local Development)

Жүйеде [Node.js](https://nodejs.org/) орнатылған болуы қажет.

```bash
# 1. Тәуелділіктерді орнату
npm install

# 2. Әзірлеу серверін қосу
npm run dev
```

Браузерде ашыңыз: `http://localhost:5173`

---

## 📦 Өндірістік нұсқаны жинау (Production Build)

```bash
npm run build
```
Дайын файлдар `dist/` қалтасына жиналады. Оларды кез келген веб-хостингке (GitHub Pages, Netlify, Vercel немесе серверге) жүктеуге болады.

Жергілікті тексеру:
```bash
npm start
```
`http://localhost:3000` мекенжайында дайын нұсқа іске қосылады.

---

## ⚡ Тез іске қосу (Windows)
Жоба қалтасындағы `start.bat` файлын екі рет басыңыз. Сервер автоматты түрде қосылып, браузер ашылады.

## 🚆 Railway-ге деплой жасау (Deploy to Railway)

1. Осы қалтаны өз GitHub репозиторийіңізге салыңыз:
   ```bash
   git init
   git add .
   git commit -m "Initial commit"
   git branch -M main
   git remote add origin https://github.com/Su1teen/zhas-erekshelik.git
   git push -u origin main
   ```
2. [railway.app](https://railway.app) сайтына кіріп, **New Project → Deploy from GitHub repo** батырмасын басыңыз.
3. `zhas-erekshelik` репозиторийін таңдаңыз. Railway автоматты түрде қосымшаны анықтап, `npm start` арқылы `server.js` файлын қосады.
4. Қосымша 1 минутта іске қосылып, ресми сілтеме береді!
